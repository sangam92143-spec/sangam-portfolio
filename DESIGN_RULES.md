# Website Design Rules

## Core Principle

Preserve the website's established visual identity and create original design decisions instead of following generic AI website patterns.

## Never Do

Do not make the website look like a generic Lovable/Bolt/v0/Framer-AI generated website.

Avoid:
- generic bento grids
- repetitive rounded cards
- excessive glassmorphism
- random glowing gradients
- generic purple/blue blobs
- oversized gradient text
- meaningless statistics
- excessive pill UI
- generic SaaS layouts
- random floating cards
- generic 3D spheres/blobs
- unnecessary visual effects
- generic AI-generated copy

## Typography

Always reuse the existing website font and typography system.

Never introduce a new font unless explicitly instructed.

## Colors

Preserve the existing color palette.

Do not introduce a new color system.

## Visual Identity

New components must look native to the existing website.

Reuse existing:
- spacing
- borders
- buttons
- cards
- typography
- animation language
- visual hierarchy

## 3D

3D elements are allowed when they genuinely improve the design.

They should be:
- original
- subtle
- purposeful
- premium
- performant
- responsive

Never add generic 3D objects simply because 3D is requested.

## Design Decision Rule

When uncertain, prioritize originality, restraint and consistency with the existing website over common AI-generated design patterns.

The goal is to make the website feel designed, not generated.
